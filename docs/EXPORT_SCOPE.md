# Public code export scope

Canonical source modules are copied without the original Git history. Runtime folders, nested source snapshots, datasets and manuscript files are excluded. Original import paths and internal project identifiers are retained.

The five frozen command-scene model candidates are included; model_lock.json identifies the selected forest. Saved summary/audit reports describe checks on the original full local archive. Their inclusion does not assert that every raw trace or verification input is present in this compact repository.

Operator cards have technical fidelity checks and no participant study. Learning improves speed error without reducing contacts. Published method comparisons are scalar adaptations rather than native reproductions. The original 540, earlier 1,512 and final 1,080 trials remain separate.

Protected final measurement payloads were neither read nor included. No manuscript, private replay state, source credential or downloaded publication is published. Existing public deterministic test keys remain recognizable as fixtures.

One original simulated nominal trace is included at the original relative path because packet policy tests read it. Other trial traces remain excluded. The harness import test requires the separately derived public sequence input.
